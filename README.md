# Fatma ÖS — Kişisel Web Sitesi

Statik kişisel portfolyo sitesi. HTML, CSS ve vanilla JavaScript dosyaları ayrı tutulmuştur.

## Dosyalar

- `index.html` — Sayfa içeriği
- `style.css` — Özel stiller
- `script.js` — Menü ve proje filtreleri
- `assets/` — Yerel proje görselleri

Tailwind CSS CDN üzerinden yüklendiği için siteyi açarken internet bağlantısı gerekir.

## GitHub Pages

Bu klasör bir GitHub deposunun köküne yüklendikten sonra **Settings → Pages → Deploy from a branch → main → /(root)** seçilerek ücretsiz yayımlanabilir. Ücretsiz hesapta GitHub Pages için depo genel (public) olmalıdır.
